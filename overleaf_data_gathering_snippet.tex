\section{Data Gathering}

The data for this project came from NBA player-game records for the 2021--22, 2022--23, and 2023--24 regular seasons. The database used for the original query was Wyatt Walsh's Basketball Dataset on Kaggle, and the analysis files in this repository use cached player-game logs so the results can be reproduced without repeatedly downloading data.

To keep the study focused on regular rotation players, a player-season was included only if the player averaged at least 20.0 minutes per game and appeared in at least 60 games that season. For each qualifying player-season, I kept games in which the player actually played and recorded the game date, minutes played, and Game Score. Game Score was used as the response variable because it summarizes a player's box-score performance in one number.

The explanatory variable was recent workload. For each player-game, I summed the minutes that same player played in his previous five games during the same season. The first five games of each player-season were removed because they did not yet have five previous games available. This left 34,831 usable player-game observations from 290 unique players.
